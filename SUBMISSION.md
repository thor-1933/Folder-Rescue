What if the game you played actually cleared your digital clutter?

I built **Taskocalypse: Folder Rescue** for Prompt Wars: a platform game where collecting files actually organizes a real folder on your device.

Automatic mode uses file-type detection and a local filename classifier to organize each pickup in the background. Manual mode lets you review or change destinations. The game ends when the eligible files are organized.

The practical details matter: files stay local, folder access requires permission, copies are verified before originals are removed, and a rescue log supports undo. There is also a playable demo, keyboard controls, and reduced-motion support.

Built with browser-native JavaScript, zero runtime dependencies, and automated tests covering both successful operations and failure recovery.
